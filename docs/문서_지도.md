## 문서 관리 원칙

같은 운영 절차를 여러 Markdown에 복사하지 않는다. 설치·운영 방법은 해당 기능의 기준 문서 하나에 두고 다른 문서는 링크만 건다.

과거 구조를 설명하는 문서는 현재 운영 문서와 섞지 않는다. 오래된 내용이 의사결정 근거로 필요하면 결정 원장이나 Git 이력으로 확인한다.

새 문서를 만들기 전에 이 지도에서 기존 기준 문서에 합칠 수 있는지 먼저 확인한다.
