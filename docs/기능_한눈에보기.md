| 알림·즉시 피드백 | 실제 변경·중요 경고를 GitHub Issue로 알리고 답글을 다음 진화에 반영 | Issue #1 · 사용자 피드백 |

| 사용자 협업 | 사람이 해야 하는 외부 설정을 구체적으로 기록 | [사용자 도움 필요](사용자_도움_필요.md) |
| 웹 대시보드 | GitHub Markdown을 뒤질 필요 없이 통합 열람 | GitHub Pages |

## 가장 중요한 원칙

이 프로젝트는 **더 많은 기능**보다 **더 나은 연구 품질**을 목표로 합니다.

AI가 새 아이디어를 생각했다고 무조건 넣지 않습니다. 과거 결정과 실험을 확인하고, 실제 이득이 있는지 판단하고, 테스트와 회귀 탐지를 통과한 변경만 유지하는 방향으로 발전합니다.
