# 프로젝트 설명서

Stock AutoResearch는 **AI가 주식시장을 연구하면서 동시에 자기 프로젝트 자체도 개선하는 자율 연구 시스템**입니다.

## 이 프로젝트가 하려는 일

사용자가 매번 종목이나 뉴스 주제를 지정하지 않아도 AI가 시장 전체를 훑고, 새 사건을 찾고, 중요도를 판단하고, 추가 질문을 스스로 만들고, 반론과 1차 자료를 검증한 뒤 결과를 GitHub에 남깁니다.

동시에 GitHub Actions가 6분마다 AI 없이 프로젝트 상태를 센서처럼 기록합니다. 관측 10개가 쌓이면 ChatGPT가 1시간 단위로 최신 웹·공식자료를 다시 조사하고, 시장 탐색·1차자료 검증·반론·국내시장 연결·매매연구·오버나이트 리스크·중복 제거·비판 검토를 거쳐 리서치와 프로젝트 개선을 판단합니다. 좋은 아이디어는 실제 코드와 화면에 반영하고, 당장 도입하기 어렵거나 위험한 아이디어는 이유와 필요한 조건을 기록합니다.

## 핵심 동작 흐름

```text
시장 전체 확인
→ 새로운 사건·공시·정책·수급 변화 후보
→ 중요도·새로움·근거 강도 평가
→ 심층 리서치
→ 반론·누락·숫자·날짜 재검증
→ 산업·종목 연결
→ 가격·거래대금·시장 반응 확인
→ 최종 보고서
→ 과거 연구와 비교
→ 이후 의미 있는 변화 감시
```

별도로 프로젝트 자체는 다음 루프를 돕니다.

```text
6분 센서 × 10
→ 시간 흐름·Health·검증·데이터 상태 기록
→ 1시간 ChatGPT 심층 리서치
→ 최신 웹·공시·기업 IR·정부 자료 재탐색
→ 반론·미확인·재탕 제거
→ 시장·종가베팅·눌림·Overnight Risk 연결
→ 필요한 변경만 적용
→ 테스트
→ 성공 시 유지
→ 악화 시 기능 단위 롤백 또는 격리
→ 결정 이유와 결과 기록
```

## 사용자의 매매 연구에 맞춘 기능

이 프로젝트의 국내시장 연구는 특히 **종가베팅과 단기스윙 눌림**을 중심으로 발전합니다.

- 1분 거래대금 절대값과 평소 대비 Burst
- 거래대금이 부족한 상승 구분
- 신규주 여러 종목의 동시 자금 유입
- 섹터·기업집단 동조 수급
- 장후반 가격·거래대금 지속성
- KRX 종가 이후 NXT 20:00까지 추가 흐름
- 다음 날 갭, MFE, MAE
- 눌림 이후 1·3·5거래일 반등/역행 통계
- 당시 KOSPI·KOSDAQ·선물·환율·금리·미국시장 등 시장 조건 동시 저장
- CPI·FOMC·고용·한국은행 등 다음날 갭에 영향을 줄 수 있는 일정 Risk Veto

## 시장 데이터

실시간 체결·가격 같은 **정량 시장 데이터**의 1순위는 Toss Open API 기반 고정 IP Collector입니다.

Toss 실시간 연결 시 실제 체결을 합산하여 1분 거래대금을 계산하고 NXT 애프터마켓까지 봅니다. Toss가 준비되지 않았거나 정규장 중 문제가 생긴 경우 키움 데이터는 fallback으로 사용할 수 있습니다.

반면 **뉴스·정책·공시·산업 변화 탐색은 멀티소스 방식**입니다. 매시간 ChatGPT가 네이버 뉴스·네이버 금융·국내 주요 경제/통신사·Reuters 등 글로벌 뉴스·Google News·일반 웹 검색을 폭넓게 사용하고, 중요 후보는 DART·KRX·정부기관·기업 IR·SEC·Fed 등 1차 자료로 다시 검증합니다. 자세한 기준은 [멀티소스 시장 리서치](멀티소스_시장리서치.md)와 [출처 정책](출처_정책.md)을 따릅니다.

주문 API는 사용하지 않습니다.

## 잘못된 개선을 막는 구조

새 기능이 보기에는 좋아도 전체 품질을 떨어뜨릴 수 있기 때문에 Regression Guard가 있습니다.

변경마다 change_id와 변경 전/후 파일 상태를 남기고 7일·30일 품질 기준선과 비교합니다. 문제가 특정 기능으로 좁혀지면 **그 기능이 바꾼 파일만 복원**합니다. 이후 다른 기능이 같은 파일을 다시 수정했다면 자동 롤백 대신 격리하여 최신 작업을 함부로 지우지 않습니다.
