# 파일 구조 안내

이 문서는 GitHub 저장소에 직접 들어왔을 때 파일과 폴더가 무엇을 의미하는지 빠르게 이해하기 위한 안내서입니다.

## 사람이 주로 보는 폴더

| 위치 | 설명 |
|---|---|
| `docs/` | 프로젝트 설명·결정·아이디어·운영 규칙 |
| `reports/` | AI가 생성한 시장 심층 리서치 |
| `site/` | GitHub Pages 대시보드 |
| `data/` | 누적 통계와 시스템 상태 |
| `prompts/` | AI 역할별 프롬프트 |
| `collector/` | 선택적 Toss WebSocket 호환 도구 |
| `deploy/` | 선택적 고정 IP Toss 배포 예시 |
| `.github/workflows/` | 자동 실행 스케줄 |

| 파일 | 역할 |

| `프로젝트_설명서.md` | 전체 프로젝트 설명 |
| `기능_한눈에보기.md` | 현재 기능 목록 |

| `실험_기록.md` | 실험과 실패·검증 결과 |

## 영어 파일이 일부 남아 있는 이유

모든 파일을 한글로 바꾸면 더 읽기 쉬워 보이지만 일부 파일은 도구 규칙과 모듈 경로 때문에 영어 이름을 유지하는 편이 안전합니다.

### GitHub/도구 표준

- `README.md` — 저장소 첫 화면 자동 표시
- `AGENTS.md` — AI 개발 지침
- `.gitignore` — Git 표준
- `pyproject.toml` — Python 패키지 표준
- `site/index.html` — 웹사이트 기본 진입 파일

### Python 내부 코드

`src/autoresearch/`의 Python 파일은 import 경로이므로 영어 이름을 유지합니다.

예:

- `market_intel.py` → 국내시장 분석 엔진
- `risk_engine.py` → Overnight Risk 엔진
- `regression.py` → 회귀 탐지·롤백
- `health.py` → Health Watchdog
- `evolution.py` → 자기진화 엔진
- `toss_collector.py` → Toss 실시간 Collector

이 파일들은 사용자가 평소 직접 열지 않아도 됩니다.

## 가장 쉬운 사용 방법

GitHub 파일을 하나씩 보는 대신 아래 두 곳을 우선 사용하면 됩니다.

1. 저장소 메인 README
2. GitHub Pages 대시보드: https://juhwan7.github.io/stock-autoresearch/

세부 설계가 궁금할 때만 `docs/`의 한글 문서를 따라가면 됩니다.


## 한글화된 설정·운영 파일

직접 찾아볼 때 역할이 바로 보이도록 다음 영역도 한글 파일명을 사용한다.

### config

- `리서치.yaml` — 리서치 실행 설정
- `점수기준.yaml` — 후보 이슈 점수화
- `출처.yaml` — 출처 우선순위
- `자기진화.yaml` — 10분 자기진화 설정
- `상태감시.yaml` — Health Watchdog
- `시장분석.yaml` — 국내 Market Tape
- `회귀탐지.yaml` — Regression Guard
- `리스크.yaml` — Overnight Risk
- `주요일정_2026.yaml` — 주요 일정 기본값

### scripts

- `대시보드_생성.py`
- `토스스냅샷_가져오기.py`
- `토스상태_요약.py`

### site

- `index.html` — 웹 표준 진입 파일이라 유지
- `기능.js` — 화면 동작
- `스타일.css` — 화면 디자인
- `data/상태.json` — 대시보드 데이터

### 시장 통계 CSV

- `종목_메타데이터.csv`
- `종목_메타데이터_예시.csv`
- `stats/종가베팅_이벤트.csv`
- `stats/눌림스윙_이벤트.csv`
