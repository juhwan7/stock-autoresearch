# 출처 정책

## 핵심 원칙

Stock AutoResearch는 한 데이터 공급자나 한 뉴스 사이트에 의존하지 않는다.

**발견은 넓게, 확정은 엄격하게** 한다.

시장 가격·체결·거래대금처럼 숫자 정확도가 중요한 값과 뉴스·테마·정책·산업 변화처럼 탐색 범위가 중요한 정보는 서로 다른 출처 계층을 사용한다.

## Tier 1 — 1차 자료

중요 사실을 확정할 때 최우선으로 사용한다.

- DART 전자공시
- KRX / KIND
- 금융위원회·금융감독원
- 한국은행
- 기획재정부·산업통상자원부 등 정부기관
- 미국 SEC EDGAR
- Federal Reserve
- BLS, BEA, U.S. Treasury 등 미국 정부기관
- 기업 IR·공식 뉴스룸·실적발표·공식 보도자료
- 거래소 공지
- 법원·규제기관·조달·계약 원문

중요한 계약, 투자금액, 생산능력, 실적, 정책 변경, 일정은 가능한 한 이 계층에서 다시 확인한다.

## Tier 2 — 시장·가격 데이터

수치형 시장 데이터를 확인할 때 사용한다.

- Toss Open API / 실시간 Collector
- KRX
- 키움 REST
- 기타 신뢰 가능한 증권사·거래소 데이터
- 공식 지수·금리·환율·원자재 제공기관

국내 실시간 1분 체결대금은 Toss를 우선하지만, **Toss가 전체 리서치의 유일한 출처라는 뜻은 아니다.**

같은 숫자가 여러 소스에서 다르면 시간 기준, 정규장/NXT 구분, 수정주가 여부, 통화·단위를 확인한 뒤 원인을 기록한다.

## Tier 3 — 고품질 뉴스·전문 매체

새 이슈를 찾고 맥락을 파악하며 1차 자료를 찾기 위한 경로로 적극 사용한다.

- Reuters
- Bloomberg
- Financial Times
- Wall Street Journal
- CNBC
- 연합뉴스
- 한국경제
- 매일경제
- 서울경제
- 이데일리
- 머니투데이
- 주요 산업 전문지

중요 사실은 가능하면 원문·공식자료로 다시 확인한다.

## Tier 4 — 포털·검색·집계

**새 이슈 발굴 범위를 넓히기 위해 적극 사용한다.**

- 네이버 뉴스
- 네이버 금융
- Google News
- 검색엔진 뉴스 결과
- 포털 증권 뉴스·종목 뉴스
- 여러 매체의 동일 이슈 집계

네이버에서 발견한 뉴스가 중요하다고 판단되면 원 기사와 1차 자료를 추가로 확인한다.

네이버 금융의 가격·거래량·시가총액 등 화면 수치는 보조 확인값으로 사용할 수 있지만, 실제 체결 기반 통계의 canonical 값은 거래소·Toss·증권사 API를 우선한다.

## Tier 5 — 탐색 전용

- 블로그
- 커뮤니티
- SNS
- Reddit
- 종목 게시판
- 출처 불명 재전송 글

이 계층은 아이디어나 시장 관심도를 찾는 데 사용할 수 있지만 단독으로 중요 사실을 확정하지 않는다.

루머가 시장에서 실제로 영향을 주고 있다면 ‘루머가 유통 중이라는 사실’은 기록할 수 있지만 루머 내용 자체를 사실로 승격하지 않는다.

## 매시간 AI 리서치의 최소 출처 다양성

의미 있는 시장 리서치를 수행할 때 한 종류의 사이트만 반복해서 보지 않는다.

가능한 범위에서 다음 묶음을 모두 확인한다.

1. 한국 포털/뉴스 탐색 — 네이버 뉴스·네이버 금융 포함
2. 국내 주요 경제·통신사
3. 글로벌 주요 뉴스
4. 관련 기업·정부·거래소·규제기관 1차 자료
5. 가격·거래대금·지수·금리 등 수치형 시장 데이터
6. 기존 Stock AutoResearch 보고서와 Claim Ledger

핵심 이슈 하나를 확정할 때는 가능한 한 서로 독립적인 출처 2개 이상을 확인하되, 1차 자료 하나가 직접적이고 충분한 경우 억지로 동일 사실을 반복하는 기사 숫자만 늘리지 않는다.

## Claim labels

- verified_fact: 강한 출처로 직접 확인된 사실
- official_claim: 이해관계자·기관이 공식적으로 밝힌 주장
- analysis: 확인된 근거에서 도출한 분석
- inference: 추가 가정이 필요한 연결
- unverified: 확인 근거가 부족한 내용

## 출처 충돌 처리

출처가 서로 다르면 숫자를 평균내지 않는다.

- 발표 시각
- 데이터 기준 시각
- 정규장 / NXT / 프리마켓 구분
- 연결 / 별도 실적
- 수정주가 여부
- 원화 / 달러 등 통화
- 계약 총액 / 프레임 계약 / 실제 발주액 차이
- 생산능력 / 실제 생산량 / 실제 판매량 차이

차이를 해결하지 못하면 ‘미확인’으로 남긴다.

## 수집 안전

- 로그인 우회, 캡차 우회, 접근통제 우회는 하지 않는다.
- 사이트가 제공하는 공개 페이지·검색 결과·공식 API·허용된 피드를 우선한다.
- 웹페이지 전체를 저장·복제하지 않고 리서치에 필요한 사실과 출처 메타데이터만 기록한다.
