# 사용자 의도

이 문서는 프로젝트가 시간이 지나도 최초 목적을 잃지 않도록 보존하는 최상위 목적 문서다.

## 최종 목표

사용자가 세세한 기능을 매번 지시하지 않아도 AI가 스스로 프로젝트를 관찰하고, 더 나은 아이디어를 찾고, 조사하고, 실제 GitHub 저장소를 개선해 나가는 프로젝트를 만든다.

단순한 자동 리서치 봇이 아니라 다음 특성을 가진 **AI가 만들어가는 프로젝트**를 목표로 한다.

1. 주식이라는 큰 주제에서 AI가 스스로 조사 대상을 찾는다.
2. AI가 프로젝트의 문제점과 개선점을 스스로 발견한다.
3. 좋은 아이디어는 실제 코드·문서·UX에 반영한다.
4. 당장 도입하기 어렵거나 좋지 않은 아이디어도 버리지 않고 이유와 함께 기록한다.
5. 어떤 기능을 왜 도입했고, 왜 보류했고, 왜 폐기했는지 시간이 지나도 추적할 수 있어야 한다.
6. 사람의 도움이 필요한 경우 무엇을 왜 해야 하는지 구체적으로 설명한다.
7. Markdown 문서에만 머무르지 않고, 필요하다면 웹 UI·대시보드·검색·시각화 등 더 읽기 좋은 형태로 진화한다.
8. 사용자가 생각하지 못한 부분도 AI가 먼저 발견하고 개선한다.
9. 프로젝트의 설명과 사용자-facing 콘텐츠는 한국어를 기본으로 한다.
10. 10분마다 프로젝트와 시장을 다시 생각한다. 단, 의미 없는 변경을 억지로 만들지는 않는다.

## 중요한 해석

“10분마다 변화”는 “10분마다 반드시 코드를 수정”한다는 뜻이 아니다.

좋은 시스템은 변경할 이유가 없을 때 변경하지 않을 수 있어야 한다. 따라서 매 10분마다 최소한 다음 중 하나는 남아야 한다.

- 새로운 개선 아이디어
- 기존 아이디어의 재평가
- 실제 코드/문서/UX 개선
- 실험
- 보류 또는 폐기 결정과 이유
- 현재 변경할 필요가 없다는 판단과 그 이유
- 사람의 도움이 필요한 항목
- 새로운 시장 조사 결과

## AI가 지켜야 할 태도

사용자의 신뢰를 “무제한 변경 권한”으로 해석하지 않는다.

프로젝트가 장기적으로 좋아지는지를 우선하며, 단기적으로 멋있어 보이는 기능보다 정확성·재현성·안정성·가독성·비용 효율을 우선한다.


## 국내시장 트레이딩 리서치 우선순위

사용자의 핵심 관심은 국내시장 단기 매매이며, 특히 **종가베팅과 단기스윙 눌림**을 우선한다.

프로젝트는 국내시장을 볼 때 다음을 중요하게 다룬다.

- 분봉 거래대금의 절대값과 종목별 평소 대비 상대 강도
- 거래대금이 실린 상승과 거래대금이 부족한 상승의 구분
- 신규상장주 여러 종목에 동시에 자금이 들어오는지
- 섹터·기업집단 종목이 같은 시간대에 동조 상승하는지
- 장 후반 14:30~15:20에 거래대금이 유지되거나 재유입되는지
- 종가베팅 후보의 다음 날 갭, 최대상승폭(MFE), 최대하락폭(MAE)
- 강한 상승 파동 이후 눌림폭·눌림기간·거래대금 감소·재가속 통계
- 성공한 종목만 고르는 것이 아니라 동일 조건의 전체 표본을 남기는 것

장세는 뉴스 제목으로 이름 붙이지 않는다. 실제 가격·분봉 거래대금·동조성·시장 폭·집중도를 근거로 먼저 구조를 설명하고, 그 뒤 이해하기 쉬운 장세 이름을 붙인다.

상세 기준은 `docs/TRADING_RESEARCH_MANDATE.md`를 따른다.
