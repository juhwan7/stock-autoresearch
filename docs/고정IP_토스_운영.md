# Toss 데이터 운영 안내

현재 기본 국내 정량 데이터 경로는 **고정 IP가 필요 없는 네이버 공개 6분 배치**다.

Toss는 정확도 보강용 선택 데이터 공급자이며, 프로젝트 실행의 필수조건이 아니다.

## 현재 권장 구조

- 기본: `data/providers/naver_batch/latest.json`
- 선택적 Toss 보강: 고정 IP self-hosted runner의 6분 REST 수집
- Toss 설정이 없거나 장애가 나도 네이버 공개 배치와 시장 리서치는 계속 동작한다.
- 주문·계좌·자동매매 기능은 사용하지 않는다.

Toss 6분 수집을 사용할 경우 자세한 설정은 [고정 IP Toss 6분 러너](고정IP_토스_러너.md)를 따른다.

기존 상시 WebSocket Collector 방식은 현재 기본 운영 경로가 아니다. 과거 방식과 현재 6분 REST 방식을 동시에 실행하면 데이터 경로와 Health 해석이 중복될 수 있으므로 새 설치에서는 사용하지 않는다.
