# 사용자 피드백

GitHub Issue **#1 · AI 진화 알림 · 사용자 피드백**에서 사용자가 남긴 피드백을 시간순으로 보존한다.

이 문서는 자기진화 Scout가 결정 원장보다 먼저 읽는 최우선 사용자 컨텍스트다.

## 지원하는 빠른 표현

- 좋아 / 유지: 비슷한 방향을 긍정적으로 기억.
- 보류: 비슷한 자동 변경을 우선 멈추고 재검토.
- 수정해줘: 다음 자기진화 최우선 수정 요청.
- 되돌려줘: CHANGE_ID를 지정하면 기능 단위 안전 롤백 요청.
- 아이디어: 새 개선 아이디어.
- 자유문장: 그대로 사용자 피드백으로 저장.

되돌려줘 요청도 이후 같은 파일에 다른 변경이 있는 경우 무조건 덮어쓰지 않는다. 기존 Regression Guard의 경로 충돌·Hash 검사를 우선한다.

민감한 API Key, 비밀번호, Secret은 Issue 댓글에 작성하지 않는다.
