# Dashboard UI 장기 결정

## 현재 기본 방향

- 화이트 테마 유지.
- 메인은 전체 원자료가 아니라 가장 중요한 시장 맥락을 우선한다.
- 기본 흐름은 AI 시장 해설 → 핵심 이슈/리스크 → 핵심 숫자 → 최근 거래일 → 상세 화면이다.
- 글로벌·리스크는 오버나잇 위험과 가까운 일정을 먼저 보여주고 미국 3거래일·매크로 상세는 접힌 상태로 둘 수 있다.
- 시스템 페이지는 현재 이상과 복구 상태를 먼저 보여주고 공급자·Regression·AI 로그·결정 원장은 기본 접힘으로 둔다.
- 이슈·리서치 전문 페이지는 전체 데이터를 보존하되 각 항목은 details로 세부를 펼친다.
- 정적 details 섹션의 펼침/접힘 상태는 localStorage로 기억하되 저장 실패 시 기본 HTML 동작으로 안전하게 fallback한다.
- 사용자에게 직접 필요하지 않은 backend 데이터는 화면에 억지로 노출하지 않는다.
- 기능이 늘어날수록 메인 화면은 더 복잡해지는 것이 아니라 더 정리되어야 한다.

## 재검토 질문

A:
- 지금 가장 먼저 보이는 것이 실제로 가장 중요한가?
- 새 데이터가 생겼다면 화면에 보여야 하는가, 내부 분석에만 써야 하는가?
- 접거나 전문 페이지로 내려보낼 정보는 없는가?

B:
- 기본 화면에 계속 보여줄 이유가 있는가?
- 중복·빈 카드·낮은 가치 정보가 공간을 낭비하지 않는가?
- 모바일에서 핵심이 첫 화면에 보이는가?

## 재도입/변경 조건

현재 접힌 상세를 다시 기본 노출하려면 사용자가 첫 화면에서 반드시 봐야 하는 정보라는 근거가 있어야 한다. 단순히 데이터가 존재한다는 이유만으로 펼치지 않는다.
