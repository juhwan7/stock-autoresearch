# Stock AutoResearch 장기 기억

이 폴더는 A/B/Recovery가 수개월~수년의 시행착오를 이어받기 위한 외부 두뇌다.

## 읽기 순서

1. memory/INDEX.md
2. memory/current/현재상태.md
3. memory/current/다음확인사항.md
4. 현재 작업과 관련된 WARM memory
5. 반복 문제나 과거 비교가 필요할 때만 COLD memory

## 계층

- current/: HOT memory. 항상 작고 최신이어야 한다.
- supervisors/: A/B/Recovery 실행별 구조화 기록.
- market/: 장기 시장 이슈·regime·반응의 재사용 가능한 기억.
- project/: 버그·기능·실험·실패·삭제·결정·공급자 기억.
- research/: 질문·가설·발견·반증·출처품질.
- lessons/: 반복해서 재사용할 교훈.
- snapshots/: 일/주/월 압축 기억.
- archive/: 평상시 읽지 않는 상세 과거.

canonical 데이터는 data/, 실행 규칙은 AGENTS.md와 docs/에 있다. memory는 이를 무작정 복제하지 않고 빠른 탐색과 연속 사고를 위한 요약·연결 계층으로 유지한다.
