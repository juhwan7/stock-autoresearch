# Stock AutoResearch

**AI가 주식시장을 스스로 연구하고, 동시에 자기 프로젝트 자체도 계속 개선하는 자율 연구 시스템**입니다.

사용자가 매번 “오늘은 무슨 종목 조사해줘”라고 지시하지 않아도 시장 전체에서 새 사건과 변화 가능성을 찾고, 중요도를 평가하고, 질문을 만들고, 1차 자료와 반론을 확인한 뒤 리서치 결과를 GitHub에 남기는 것을 목표로 합니다.

또한 프로젝트는 **10분마다 자기 자신도 점검**합니다. 더 좋은 데이터 수집법, 통계, 문서 구조, UI, 오류 복구 방식이 보이면 개선을 시도하고, 도입하지 않은 아이디어도 이유와 함께 장기 기록으로 남깁니다.

> 이 저장소는 기존 `market-memo`와 완전히 별개의 독립 프로젝트입니다.

## 이 프로젝트가 자동으로 하는 일

### 1. 시장에서 조사할 주제를 스스로 찾습니다

단순히 기사 제목을 모으는 것이 아니라 다음 종류의 변화를 찾습니다.

- 한국·미국 주요 시장 변화
- 공시·실적·가이던스·계약·수주
- 정부·규제·금리·정책 변화
- 산업·공급망·기술 변화
- 거래대금·수급·가격의 비정상 변화
- 기존 연구 내용과 달라진 새 사실

새 이슈를 찾은 뒤 다음을 평가합니다.

```text
새로운가?
→ 시장 영향이 큰가?
→ 공식 근거가 있는가?
→ 추가 조사 가치가 있는가?
→ 실제 시장 반응이 있는가?
```

점수가 낮거나 기존 내용의 반복이면 깊게 조사하지 않습니다.

### 2. AI가 질문을 만들고 심층 조사합니다

선정된 주제는 바로 결론부터 내리지 않습니다.

```text
핵심 질문 생성
→ 1차 자료 조사
→ 숫자·날짜·계약·생산능력 확인
→ 반대 근거 조사
→ 누락된 질문 추가
→ 필요 시 재조사
→ 산업·종목 연결
→ 최종 보고서
```

특히 다음을 구분합니다.

- 확인된 사실
- 기업·정부 등 당사자 주장
- 제3자 분석
- AI 추론
- 아직 미확인

### 3. 같은 내용을 계속 반복하지 않습니다

기존 연구 결과와 비교해 **새로 추가된 사실과 상태 변화**를 중심으로 다시 연구합니다.

이전 연구에서 이미 확인한 사실을 매번 새 보고서처럼 반복하는 구조를 피합니다.

## 국내시장 연구 — 종가베팅·단기스윙 중심

사용자의 주된 연구 전략은 **종가베팅과 단기스윙 눌림**입니다.

따라서 국내시장에서는 뉴스만 보는 것이 아니라 실제 시장 돈의 흐름을 중요하게 봅니다.

### 1분 거래대금

- 종목별 실제 1분 거래대금
- 평소 대비 거래대금 Burst
- 5억·10억·20억·50억원 이상 분봉 반복 횟수
- 가격만 오르고 거래대금이 부족한 종목 분리
- 장후반 거래대금 지속성

같은 +5% 상승이라도 거래대금이 충분한 상승과 얇은 거래로 오른 상승을 동일하게 보지 않습니다.

### 신규주 장세

특정 신규주 하나만 보는 것이 아니라 여러 신규주에서 동시에 큰 분봉 거래대금이 반복되는지를 봅니다.

예:

```text
신규주 A 1분 20억
신규주 B 1분 15억
신규주 C 1분 30억
→ 같은 시간대 동시 발생
→ 신규주 집단으로 자금이 몰리는 장세 가능성
```

### 섹터·기업집단 동조 수급

단순히 이름이 비슷하거나 같은 테마라는 이유로 묶지 않습니다.

예를 들어 한화오션·한화시스템·한화 등 관련 대형주가 **같은 시간대에 상승 + 거래대금 Burst**를 보이는지를 확인합니다.

### 종가베팅 통계

종가베팅 후보 전체를 저장하고 다음 거래일 결과를 누적합니다.

- 다음 날 갭
- MFE: 진입 후 최대 유리 움직임
- MAE: 진입 후 최대 불리 움직임
- +3%·+5% 도달 비율
- -3%·-5% 역행 비율
- 당시 시장 상태
- 당시 Risk 상태
- NXT 장후 흐름

성공한 차트만 골라 통계를 만들지 않습니다.

### 눌림 단기스윙 통계

- 이전 상승 파동
- 거래대금 크기
- 눌림 폭
- 5일선·20일선 위치
- 거래대금 감소 여부
- 1·3·5거래일 MFE/MAE
- 실제 +5%·+10% 반등이 나온 표본의 이전 하락폭

을 누적합니다.

자세한 기준은 [매매연구 원칙](docs/매매연구_원칙.md)을 참고하면 됩니다.

## Toss-first 실시간 시장 데이터

국내 시장 데이터의 1순위는 **토스증권 Open API 기반 Collector**입니다.

### Toss가 연결된 경우

```text
Toss trade:kr
→ 실제 체결
→ Σ(체결가 × 체결량)
→ 정확한 1분 거래대금
→ Market Tape
```

KRX 정규장뿐 아니라 NXT 대상 종목의 **15:40~20:00 애프터마켓**도 추적합니다.

저장하는 주요 값:

- NXT 마지막 가격
- KRX 종가 대비 프리미엄/디스카운트
- NXT 누적 거래대금
- 최대 1분 거래대금
- 10억·20억원 이상 분봉 반복
- NXT 마지막 가격 기준 다음 날 갭·MFE·MAE

### Toss가 없을 때

KRX 정규장에서는 키움 REST 데이터를 fallback으로 사용할 수 있습니다.

키움 fallback의 1분 거래대금은 근사치이므로 실제 체결대금과 명확히 구분합니다.

**주문·계좌 자동매매 기능은 구현하지 않습니다.**

- [토스데이터 운영계획](docs/토스데이터_운영계획.md)

## 10분 자기진화 시스템

이 프로젝트의 가장 큰 특징입니다.

10분마다 시장만 보는 것이 아니라 **프로젝트 자신도 다시 봅니다.**

```text
현재 프로젝트 읽기
→ 불편/오류/개선 가능성 탐색
→ 과거 아이디어와 중복 확인
→ 기대효과·위험 평가
→ 안전한 경우 실제 수정
→ 테스트
→ 유지 / 롤백 / 격리
→ 이유 기록
```

### 무조건 바꾸지는 않습니다

좋은 자기진화는 “매번 뭔가 바꾸는 것”이 아닙니다.

개선 효과가 작거나 근거가 약하면 **변경 없음**이 정상 결과입니다.

### 프로젝트가 기억하는 것

- [결정 원장](docs/결정_원장.md) — 왜 도입했는가
- [아이디어 보드](docs/아이디어_보드.md) — 채택·실험·후보·보류·폐기
- [실험 기록](docs/실험_기록.md) — 실제 실험 결과
- [AI 변경기록](docs/AI_변경기록.md) — 실제 바뀐 것
- [사용자 도움 필요](docs/사용자_도움_필요.md) — AI 혼자 해결할 수 없는 일

## Regression Guard — 잘못된 개선 자동 감시

새 기능이 테스트는 통과했지만 며칠 뒤 리서치 품질을 떨어뜨릴 수도 있습니다.

그래서 자동 회귀 탐지 구조가 있습니다.

### 전체 저장소를 과거로 되돌리지 않습니다

변경마다 `change_id`를 만들고 해당 기능이 바꾼 파일을 기록합니다.

예를 들어 100개의 작업 중 37번째 기능이 문제라면:

```text
1~36 유지
37번 기능만 복원
38~100 유지
```

단, 37번째 기능 이후 같은 파일을 다른 기능이 다시 수정했다면 자동 롤백으로 최신 변경을 덮어쓰지 않고 **격리(quarantine)** 합니다.

기준선:

- 최근 7일 품질
- 최근 30일 품질
- 리서치 품질
- Health 상태
- 데이터 완성도

자세한 내용은 [회귀탐지 롤백](docs/회귀탐지_롤백.md)에 있습니다.

## 프로젝트의 방향

이 프로젝트는 완성된 프로그램이 아니라 **AI와 함께 계속 진화하는 연구 시스템**을 목표로 합니다.

새 기능을 많이 넣는 것이 목적이 아니라:

**더 정확하게 보고 → 더 잘 의심하고 → 더 잘 기록하고 → 잘못된 개선은 되돌리고 → 시간이 지날수록 더 나은 연구 시스템이 되는 것**
